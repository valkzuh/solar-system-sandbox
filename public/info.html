Black Hole Visualizer

This visualizer uses a real-time GPU ray-marcher with Kerr-inspired light bending and radiative transfer, plus a Rust backend that computes Kerr metrics. The visuals are physically motivated (spectral emission, Doppler/gravitational shifts, optical depth), while derived values (horizon, ISCO, photon orbits, shadow boundary) use standard formulas for a rotating black hole.

Units And Constants

  • Mass input is in solar masses (Msun).
  • Spin parameter is dimensionless: a* = Jc / (GM^2).
  • Lengths are measured in meters internally and displayed in km / AU.
G = 6.6743e-11 m^3 kg^-1 s^-2
c = 299,792,458 m/s
Msun = 1.98847e30 kg

Gravitational Radius

The gravitational radius sets the unit scale for Kerr geometry. 

rg = GM / c^2
rs = 2rg  (Schwarzschild radius)

Event Horizon (Kerr)

The Kerr outer event horizon radius is 

r+ = rg * (1 + sqrt(1 - a*^2))

Spin is clamped to 0.998 to avoid numerical instability near extremality.

ISCO (Innermost Stable Circular Orbit)

We use the standard Kerr ISCO formula, which differs for prograde and retrograde disks. 

Z1 = 1 + (1 - a*^2)^(1/3) * ((1 + a*)^(1/3) + (1 - a*)^(1/3))
Z2 = sqrt(3a*^2 + Z1^2)

r_ISCO(prograde) = rg * (3 + Z2 - sqrt((3 - Z1)(3 + Z1 + 2Z2)))
r_ISCO(retrograde) = rg * (3 + Z2 + sqrt((3 - Z1)(3 + Z1 + 2Z2)))

The disk inner edge in the renderer is tied to r_ISCO, scaled by the UI “Inner (x ISCO)” factor.

Photon Orbits

Equatorial circular photon orbit radii in Kerr spacetime: 

r_ph(prograde) = 2rg * (1 + cos((2/3) * arccos(-a*)))
r_ph(retrograde) = 2rg * (1 + cos((2/3) * arccos(a*)))

Black Hole Shadow Boundary

For an observer at infinity with inclination angle theta, the apparent shadow is computed from constants of motion (xi, eta) of spherical photon orbits. The screen coordinates are: 

alpha = -xi / sin(theta)
beta  = sqrt(eta + a*^2 cos^2(theta) - xi^2 cot^2(theta))

We sweep through the photon region to generate a closed curve. When a* is near zero, the shadow becomes a circle of radius sqrt(27) rg.

Ray-Traced Light Bending (Approximate)

Each pixel integrates a null ray through a Kerr-inspired field. We use a GR-motivated deflection term (2M / r^3) and a frame-dragging term that rotates the ray around the spin axis. This is a fast approximation to full Kerr geodesics, but it reproduces the correct qualitative bending and spin-driven asymmetry. 

d^2x/dλ^2 ≈ -2M * r / |r|^3  +  Ω_frame × v
Ω_frame ∝ a M / r^3

The final ray direction is then used to sample the background sky, so stars are lensed by the same bending the disk experiences.

Radiative Transfer + Spectral Rendering

The disk is modeled as a thin, optically active slab. Along each ray we solve a simple emission/absorption update: 

I_out = I_in * exp(-τ) + S * (1 - exp(-τ))
τ = ∫ α ds

Emission is sampled from a Planck spectrum using three wavelengths (R/G/B) and shifted by the combined Doppler + gravitational redshift factor g. This gives a physically motivated color shift and brightness beaming across the disk. 

g = sqrt(1 - rs / r) / (gamma * (1 - beta cos(theta)))
Omega = 1 / (r^(3/2) ± a)

Spacetime Grid

The grid is a visual aid that shows the same lensing warp applied to a set of orthogonal lines. Near the photon region the lines bend strongly and may break inside the shadow boundary.

Eddington Luminosity

The Eddington luminosity is provided for scale: 

L_edd = 1.26e31 W * (M / Msun)

ISCO Orbital Period

For interpretability we report a Newtonian orbital period at r_ISCO: 

T = 2 pi * sqrt(r_ISCO^3 / (GM))

This is not a full relativistic orbital period; it is a useful timescale reference.

Accretion Disk Model

We use a Shakura–Sunyaev-inspired temperature profile with mass and accretion scaling, then apply Doppler/gravitational shifts to the emitted spectrum: 

T(r) ∝ [ (1 - sqrt(r_in / r)) / r^3 ]^(1/4)
T_obs = g * T_em

Disk thickness controls the vertical density profile, which sets optical depth and self-shadowing. A mild limb-darkening term dims grazing angles.

Jets And Beaming

Jet brightness is scaled by a combination of spin, accretion, and the “Jet power” control. This is a stylized proxy for Blandford–Znajek-like behavior, not a full magnetohydrodynamic model.

Pulsar Mode

Pulsars are neutron stars, not black holes. The pulsar preset swaps the black hole core for a magnetized star with sweeping beams. We include weak-field light bending around the compact star and a lighthouse beam model. 

alpha ≈ 2 rs / b   (weak-field deflection)
m(t) = R_spin(Ω t) · m0
I_beam ∝ exp(-theta^2 / 2σ^2)

Backend API

The frontend queries the local Rust server for physics metrics. 

GET /api/metrics?mass=10&spin=0.6&inclination=35&disk_sense=prograde

Response fields:

  • rg_m, rs_m, r_plus_m: gravitational, Schwarzschild, and horizon radii
  • isco_m: ISCO radius
  • photon_pro_m, photon_retro_m: photon orbit radii
  • shadow_radius_rg: shadow radius in units of rg
  • shadow_path: list of {x,y} points in units of rg
  • eddington_w, isco_period_s: luminosity and orbital period

Limitations

  • Kerr geodesics are approximated for real-time speed.
  • No full GRMHD, polarization, or plasma radiative transfer.
  • ISCO period is Newtonian for simplicity.
  • Disk turbulence is procedural, not MHD.
